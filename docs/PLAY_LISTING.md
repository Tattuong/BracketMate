# Google Play listing — BracketMate

Package: `com.BracketMateMNG.BracketMate`

## Title

BracketMate

## Short description

Small tournaments: single elimination, byes, results, and a schedule you can share.

## Full description

BracketMate is for one club manager. Add teams, build a single-elimination schedule, handle an odd number of teams, enter a result so the next match updates, then send the schedule and the result to the group. Data stays on the device.

Remote config: https://api2.blwsmartware.net/N302.json — when disable=1, the Play purchase popup is hidden. The shop still opens.
