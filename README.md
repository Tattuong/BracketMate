# BracketMate

Small club tournaments. One manager, on this device.

Package: `com.BracketMateMNG.BracketMate`

Remote config: [N302.json](https://api2.blwsmartware.net/N302.json) — `disable=0`, `code=FULL_IAP`. `disable=1` only hides the Google Play Billing popup.

MVP: single elimination. Add teams, balance the bracket when the count is odd, enter a result so the winner advances, and share the schedule and the result.
